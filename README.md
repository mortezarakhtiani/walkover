# Walkover

Next.js App Router project for the Walkover website and storefront.

## Run locally

```bash
npm install
npm run dev
```

- `/` is the Walkover website landing page.
- `/site-landing` remains available as its original URL.
- `/landing-v2` is the storefront landing page.
